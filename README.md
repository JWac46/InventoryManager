 # Inventory Manager

Inventory Manager is a project for organizing inventory records and keeping stock information up to date.

## About

The project is intended to provide a straightforward way to manage items, record their quantities, and review current stock. Keep item details and stock changes accurate so the inventory remains useful.

## Using the project

1. Add an item and its relevant details.
2. Update its quantity when stock is received, used, or adjusted.
3. Review the inventory records to check what is currently available.
